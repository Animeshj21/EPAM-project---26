# 🏦 JavaScript Bank Customer Page

A simple **Bank Customer Dashboard** developed using **HTML, CSS, and JavaScript**.

This project was created as part of a JavaScript case study to demonstrate DOM manipulation, event handling, form validation, and LocalStorage.

---

## 📌 Features

- Customer Dashboard
- View Current Balance
- Deposit Money
- Withdraw Money
- Transfer Money
- Transaction History
- Live Date & Time
- LocalStorage Support
- Responsive Design

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
